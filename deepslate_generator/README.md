# Deepslate Generator (NeoForge 26.2.0.95)

Cuando agua y lava hacen contacto y se generaría cobblestone, se genera deepslate.

## Compilar
1. Instala JDK 25.
2. En esta carpeta: `./gradlew build` (Windows: `gradlew.bat build`)
3. El .jar queda en `build/libs/deepslategen-1.0.0.jar` -> ponlo en tu carpeta `mods`.
